# NEAR × AI Course — Overview & Roadmap

A **hands-on course** for beginners. You start from the absolute basics (GitHub, IDE, API keys, tokens, context) and finish by deploying your own AI agent, controlling the NEAR blockchain, and presenting a real product — all **without writing code by hand**. You give prompts to AI; AI does the work.

The course is built around three NEAR pillars:

- **agent.near.ai** — deploy your own secure AI agent (IronClaw) in one click.
- **cloud.near.ai** — NEAR AI Cloud: a private, verifiable LLM API (models run in hardware-sealed enclaves).
- **Confidential Intents** — private, cross-chain money (NEAR × ZCash).

## Who it's for

Beginners — no coding required. You need a computer, a GitHub account, ~$2 on a card for API credits, and a Telegram account. Every lesson is hands-on: you follow prompts and watch real things happen.

## What you'll be able to do after the course

- Set up a complete AI development environment (GitHub, Zed, API keys, AGENTS.md)
- Understand tokens and context — and stop overpaying
- Deploy your own secure agent (IronClaw) and run it 24/7 via Telegram
- Use the NEAR AI Cloud private LLM API and understand attestation (verify, don't trust)
- Create a NEAR wallet, use Intents and explain confidential Intents
- Extend agents with MCP servers and skills
- Build, ship, and present a real NEAR project

## How this course works

Every lesson follows the same loop:

1. Understand **why** (a short concept section)
2. **Do** it — you copy a prompt into your AI assistant (Zed), it does the work
3. **Verify** — check the concrete result (a link, a message, a transaction hash)
4. **Fix** — if something breaks, use the troubleshooting prompts

**Golden rule: you don't write code or files by hand. You paste prompts and review results.**
