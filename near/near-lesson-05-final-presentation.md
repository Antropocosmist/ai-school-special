# NEAR Lesson 5: Final Presentation

**Duration:** 1.5 hours · **Format:** live demos

## Lesson Goal

Present the project you built — live demo, what you learned, what's next. This is the payoff of the whole course.

## Prerequisites

- NEAR Lesson 4 done (a working project + a screenshot)

---

## Part 1 — Prepare your 3-minute demo (20 min)

Structure it as:

1. **What it does** — one sentence.
2. **Live demo** — run it (not slides, the real thing).
3. **How it's built** — agent + NEAR + the skill/MCP you used.
4. **What was hard** — one honest obstacle and how you solved it.
5. **What's next** — one idea to extend it.

## Part 2 — Present (5 min each)

- Demo first, explain second.
- Screenshots as a backup if something breaks.

## Part 3 — Feedback & next steps

- Collect feedback (peers + instructor).
- File your project: link it in the wiki and push to GitHub.
- Decide: keep building, join a NEAR hack-night, or mentor the next group.

---

## Homework

1. Present (done in class).
2. Push the project to GitHub and share the link.
3. Write a 5-line project summary for the group.

## Result

You've shipped and presented a real agent + NEAR project. You're a builder now.
